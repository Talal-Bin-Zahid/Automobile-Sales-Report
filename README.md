## 📌 Project Overview

The **Automobile Sales Analysis Dashboard** is an interactive **Power BI analytics solution** developed to help **used car dealership managers, analysts, and decision-makers** monitor sales performance, evaluate vehicle pricing, and optimize inventory strategies.

The dashboard consolidates large-scale automobile sales data and transforms it into **actionable business intelligence**, enabling stakeholders to:

* Identify high-revenue vehicle makes, models, and body types
* Analyze pricing behavior against mileage, condition, and transmission
* Compare actual selling prices with **industry benchmark valuations (MMR)**
* Track sales performance trends over time
* Support data-driven pricing, inventory planning, and forecasting decisions

---

## 🎯 Business Objectives

* Improve pricing accuracy by aligning sale prices with market benchmarks
* Maximize profitability by prioritizing high-performing vehicle categories
* Understand depreciation trends driven by mileage and condition
* Detect overpricing or underpricing using MMR variance analysis
* Enable leadership to make faster, data-backed decisions

## 📊 Key Performance Indicators (KPIs)

| KPI                           | Value             | Description                                                           |
| ----------------------------- | ----------------- | --------------------------------------------------------------------- |
| **Total Sales Revenue**       | **$8 Billion**    | Aggregate revenue generated from all used vehicle sales               |
| **Total Cars Sold**           | **550,000 Units** | Total number of vehicles sold across all segments                     |
| **Average Selling Price**     | **$13,610**       | Mean selling price of vehicles                                        |
| **Average Odometer**          | **68,320 Miles**  | Average mileage of sold vehicles                                      |
| **Average Vehicle Condition** | **30.67**         | Average condition score of sold vehicles                              |
| **MMR Variance**              | **$88 Million**   | Net difference between actual selling prices and MMR benchmark values |

### 📘 MMR (Manheim Market Report)

MMR represents the **industry-standard valuation benchmark** for used vehicles.

**MMR Variance Formula:**

> *MMR Variance = Actual Selling Price – MMR Value*

* **Positive Variance:** Vehicles sold above market benchmark
* **Negative Variance:** Vehicles sold below market benchmark
